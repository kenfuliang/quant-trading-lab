# Canonical leaderboard construction

The [leaderboard](../leaderboard.md) is the single maintained owner for current
cross-study navigation and within-context ranks. Original reports and receipts
retain evidence authority. This is saved-result documentation work under
[GRS](../research-standard.md) and [documentation conventions](../README.md),
with zero financial runs, imports, downloads, services, agent launches or broker
operations. [Verification receipt](evidence/2026-10-28-leaderboard.json).

The primary checkout contains the historical financial evidence not present in
the newer isolated main-based management-skill checkout. This document therefore
lives alongside those original results in the primary workspace. Existing dirty
work is preserved; only this task's new documents and minimal README/doc-map links
are added. No branch switch, algorithm change, commit or publication occurs.

## Coverage and method

Nine original task reports and nine receipts were hash-bound before construction.
Selected result tables were copied at source precision, sorted by reported Calmar
within context; displayed-precision ties share rank. Negative drawdown signs are
normalized to positive depth. No metric is rerun or inferred from rounded values.
Eleven tables contain39 rows, including repeated controls, not39 independent
strategies/trials. Dates, capital, costs, financing, execution and exposure limits
are named. Historical sector treatment, repaired classification treatment and
cost/delay stress remain separate. Earlier conditional versions stay archived.

Coverage includes completed stock/ETF selection, funded T11 gate comparison,
stock overlays, repaired sector-control study, sector ETFs and CAPM/Dual Thrust/
pairs negative baselines. G-Score is blocked and synthetic-only stage work is
unranked. Local strategy/leverage grids are archive links, not silently merged
into hosted ranks. This is curated coverage, not a proof of exhaustive historical
reconciliation or a financial promotion decision.

## Verification and lesson

Verified all39 displayed rows against the source tables, all11 within-table
Calmar ranks, local links and unchanged hashes for all18 source reports/receipts.
The repository documentation check passed for137 files. No financial
metric estimate is produced by these checks. Browser URLs come from saved reports;
services are not started and current server availability is unverified.

Lesson: different growth, risk and recovery leaders can coexist. A single readable
entrypoint must keep sample/cost/exposure distinctions and negative evidence visible,
rather than collapse them into a universal winner. Future completed studies update
this same document and preserve their original evidence.
