# Trading project entrypoint

Locate the repository containing `paper_trading/` and `docs/README.md`.
For an `/ask-<role>` consultation, select the matching advisory skill from the
[role catalog](../../../docs/skills.md#available-advisory-skills).
Read [current project status](../../../README.md) and the
[skill hierarchy](../../../docs/skills.md). Select the narrowest available workflow
whose trigger matches the request, then read its SKILL.md. Use the canonical SOP
directly when a planned skill does not yet exist; do not claim it is installed.

For a listing/planning request, return the relevant hierarchy and readiness. For
an action request, continue within its scope using the selected procedure.
Route only to available skills or explicit document paths; this is not an agent
dispatcher and does not authorize broker actions.

Completion means the user has a clear workflow/owner and either the requested
result with evidence or the specific prerequisite that prevents it. Keep roadmap
priority and capability verification in their canonical owners.
