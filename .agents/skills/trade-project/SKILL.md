# Trading project entrypoint

Locate the repository containing `paper_trading/` and `docs/README.md`.
Read [current project status](../../../README.md) and the canonical
[teams and skills catalog](../../../docs/skills.md).

For `/ask-*` consultation, use the catalog's exact prefix mapping. For a task,
select its narrowest available workflow by trigger, then read the linked SKILL.md
and canonical procedure. Use the documented SOP directly when a planned skill is
unavailable, and state that readiness limit. Each research stage requires its own
scope; selecting one does not automatically launch the next.

For research progress, evidence reconciliation or multi-owner closure, select
trade-research-management; `/ask-pm` selects its advisory contract in the catalog.

For developing one algorithm stage, select trade-stage-development for its component
contract and route specialist work through the catalog.

For a listing/planning request, explain the relevant catalog entries and readiness.
For an action request, continue using the selected procedure within the requested
scope. This router does not dispatch agents or authorize broker actions.

Completion means a clear workflow/owner and either the requested result with
evidence or the specific prerequisite preventing it. Keep roster, routing and
readiness updates in the catalog, priorities in the roadmap, and capability
verification in the capability matrix.
