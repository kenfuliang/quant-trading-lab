Metric definitions and limitations
  • Full-period Calmar: CAGR / absolute full-period maximum daily-close drawdown.
  • Annual Calmar: calendar-year return / absolute within-year maximum daily-close drawdown. This is a one-year window, not a trailing three-year Calmar.
  • Sharpe: mean daily simple portfolio return / sample standard deviation × √252, with 0% risk-free rate. Annual scores use only that year's sessions, including the first session's return from the prior year-end balance. The synthetic zero-return anchor is excluded.
  • Annual return: year-end equity / previous year-end equity − 1; the first year uses initial capital.
  • Annual drawdown: high-water mark resets to the previous year-end balance; losses crossing years require the full-period drawdown too.
  • N/A: Calmar has no rank when drawdown is zero; Sharpe has no rank with fewer than two daily returns or zero daily variance. Equal finite scores share a rank. Ranks use unrounded scores.

Cash dividends retained without automatic reinvestment. Commissions and modeled spread/slippage included. No borrowing or taxes; zero cash interest. Daily closes do not capture intraday losses. First evaluation session: January 3, 2005.
