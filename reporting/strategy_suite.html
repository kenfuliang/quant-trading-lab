Exploratory historical comparison. All tested variants use the same historical SPY dataset; this is in-sample research, not untouched out-of-sample evidence. Execution: ID19 overnight exposure buys at the modeled close and exits at the next open; other cases rebalance at the next open. Nominal exposure is a cap for volatility, drawdown and CPPI overlays: actual exposure can be lower. All use the same cost and financing assumptions.

Rankings

Full-period return is CAGR; annual return is that calendar year's portfolio return. Drawdown uses daily closes, including the period-opening equity anchor. Annual Calmar = annual return / |annual drawdown|; full-period Calmar = CAGR / |full-period drawdown|. Sharpe annualizes daily excess returns with cash interest set to zero. Undefined ratios are unranked. Negative ratios need joint inspection of return and loss.
